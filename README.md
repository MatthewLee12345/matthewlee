# Matthew Lee

Static portfolio for matthewjslee.com. No build step or package install is required.

## Local preview

Run `python3 -m http.server 8765` from the repository and open http://localhost:8765.

- `index.html`: biography, research, resume, and contact.
- `music.html`: film scoring, original compositions, and B2B.mp3.
- `styles.css`: responsive layout, type, and color tokens.
- `script.js`: accessible mobile menu, one-track-at-a-time playback, and legacy hash redirects.
- `resume.pdf`: user-supplied Lee-Matthew.pdf, copied without alterations.
