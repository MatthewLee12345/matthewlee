# Matthew Lee — portfolio

Five standalone pages, self-hosted fonts, and vanilla JavaScript. No build step or install is required.

## Preview

With Node.js 22 or newer, run `npm run dev` in this folder. Open http://localhost:4173. The server binds to localhost only.

- Home: `index.html`
- About: `about.html`
- DJ: `dj.html`
- Projects: `projects.html`
- Film scoring: `film-scoring.html`

Optimized files are in `assets/`. See [asset sources](assets/SOURCES.md) for image credits and font licenses.

## Social profiles

The [DJ page](https://matthewjslee.com/dj.html#listen) embeds Instagram’s public profile for @b2b.mp3 and TikTok’s creator profile for @b2b1994. Each platform supplies its own follower total and recent media. Both work on GitHub Pages without credentials. Each heading links directly to the corresponding profile.

## Media and publication

Porcelain Partings is a local HTML5 video with H.264 picture, AAC audio, fast-start metadata, and a still from the supplied film. The other two scores load YouTube players on click and retain direct YouTube links. All three original orchestral recordings and score PDFs remain accessible.

GitHub Pages serves the static files from the repository root at [matthewjslee.com](https://matthewjslee.com/). The optimized *Porcelain Partings* MP4 is about 25 MB. Recordings and sheet music are in `Compositions/`, and competition film posters are in `Film Scores/`.
